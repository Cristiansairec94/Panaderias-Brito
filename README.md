# 🥖 Panadería Brito - Sistema Web de Gestión y Punto de Venta

Sistema integral para la panadería de **Don Toño Brito**, que incluye Punto de Venta (POS) rápido, control de inventario de materias primas y panes horneados, gestión de encargos de pastelería y reportes diarios de caja.

---

## 🚀 Inicio Rápido en Local

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

---

## 👥 Guía para el Equipo de Desarrollo

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/Cristiansairec94/Panaderias-Brito.git
   cd Panaderias-Brito
   npm install
   ```

2. **Crear tu rama de trabajo:**
   ```bash
   git checkout -b feature/nombre-de-tu-modulo
   ```

3. **Subir tus cambios:**
   ```bash
   git add .
   git commit -m "Descripción clara de tu cambio"
   git push origin feature/nombre-de-tu-modulo
   ```

4. **Crear Pull Request en GitHub** y avisar a los compañeros.
