# 🥖 Panadería Brito - Sistema Web de Gestión y Punto de Venta

Sistema integral para la panadería de **Don Toño Brito**, que incluye Punto de Venta (POS) en tiempo real, inventario de insumos, gestión de pedidos especiales y reportes de caja.

---

## 🚀 Inicio Rápido para el Equipo (Solo 2 comandos)

Para que tus compañeros configuren todo automáticamente en su máquina:

1. **Clonar el proyecto:**
   ```bash
   git clone https://github.com/Cristiansairec94/Panaderias-Brito.git
   cd Panaderias-Brito
   ```

2. **Configuración automática (instala dependencias y configura Supabase):**
   ```bash
   npm run setup
   ```

3. **Iniciar el sistema:**
   ```bash
   npm run dev
   ```
   Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

---

## 🌿 Flujo de Trabajo con Antigravity

1. **Crear una rama para tu tarea (NUNCA programar directo en `main`):**
   ```bash
   git checkout -b feature/mi-modulo
   ```
2. **Pedirle a Antigravity que desarrolle tu pantalla o función.**
3. **Subir tus cambios y crear Pull Request:**
   ```bash
   git add .
   git commit -m "Descripción de lo que hiciste"
   git push origin feature/mi-modulo
   ```
4. **Vercel generará un enlace de prueba automático** para que tus compañeros lo revisen antes de hacer merge a `main`.
